# 自定义枪械永续兼容：救援

本模组是[自定义枪械永续](https://github.com/XColorful/Custom-Gun-Continued)的兼容模组。
- 提供 [PlayerRevive](https://github.com/CreativeMD/PlayerRevive) 兼容支持

---

`该模组需要安装在服务端，客户端可选`

## 使用说明

### 前置模组

- 自定义枪械永续
    - [CurseForge](https://www.curseforge.com/minecraft/mc-mods/custom-gun-continued) | [Modrinth](https://modrinth.com/mod/custom-gun-continued) | [Github Releases](https://github.com/XColorful/Custom-Gun-Continued/releases)
- PlayerRevive
    - [CurseForge](https://www.curseforge.com/minecraft/mc-mods/playerrevive) | [Modrinth](https://modrinth.com/mod/playerrevive)

### 主要特色

游戏内启用/禁用服务端功能：
- `/cgccrevive [config] [bool]`

（可选）游戏内启用/禁用客户端功能，不影响服务端是否启用：
- `/cgccreviveclient [config] [bool]`

# CGC Compat: Revive

This mod is a compatibility mod for [Custom Gun Continued](https://github.com/XColorful/Custom-Gun-Continued).
- Provides compatibility support for [PlayerRevive](https://github.com/CreativeMD/PlayerRevive)

---

`This mod needs to be installed on the server; client installation is optional.`

## Usage Instructions

### Prerequisites

- Custom Gun Continued
    - [CurseForge](https://www.curseforge.com/minecraft/mc-mods/custom-gun-continued) | [Modrinth](https://modrinth.com/mod/custom-gun-continued) | [Github Releases](https://github.com/XColorful/Custom-Gun-Continued/releases)
- PlayerRevive
    - [CurseForge](https://www.curseforge.com/minecraft/mc-mods/playerrevive) | [Modrinth](https://modrinth.com/mod/playerrevive)

### Main Features

Enable or disable server-side features in-game:
- `/cgccrevive [config] [bool]`

(Optional) Enable or disable client-side features in-game, which does not affect server-side settings:
- `/cgccreviveclient [config] [bool]`
